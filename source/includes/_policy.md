<h2 id="disk-expansion">저장 공간 증설 요청</h2>

계정 당 기본 저장 공간(NAS <code>/shared/home/계정명</code>)은 <span style='background-color:#fff5b1; color:red'>100GB</span> 로 제한되어 있습니다. 추가 공간이 필요한 경우, 아래 양식의 각 항목을 채운 뒤 서버실 공식 이메일 <b>aix-server@inha.ac.kr</b> 로 보내주시면 사유 검토 후 증설해 드립니다.

| 항목 | 설명 | 작성 예시 |
|---|---|---|
| 계정 | 서버 로그인 계정명 | `sujin` |
| 신청자 이름 | 신청자 본인 이름 | 김수진 |
| 학번 | 학번 (교직원은 사번) | 12345678 |
| 이메일 | 연락 가능한 이메일 | `sujin_k@inha.edu` |
| 필요 용량 | 추가로 필요한 용량 | 500GB |
| 사용기간 | 증설이 필요한 기간 | 신청일 ~ 2026년 12월 31일 |
| 증설 사유 | 추가 공간이 필요한 이유 | 비디오 데이터셋 용량이 커서 저장 공간 증설이 필요함 |
| 사용 데이터셋 | 사용할 데이터셋 이름 | EgoExo4D |

> 아래 양식을 복사하여 작성 후 aix-server@inha.ac.kr 로 보내주세요

```
[인공지능융합연구센터 GPU 서버실 디스크 용량 증설 요청]
계정:
신청자 이름:
학번:
이메일:
필요 용량:
사용기간:
증설 사유:
사용 데이터셋:
```

<aside class="notice">
증설은 <b>사유 검토 후 승인</b>되며, 신청하신 용량·기간이 그대로 보장되지 않을 수 있습니다. 사용기간 종료 후에는 기본 용량(100GB)으로 환원될 수 있습니다.
</aside>


<h2 id="local-disk-policy">로컬 디스크 사용 정책</h2>

| 구분 | 경로 | 노드 | 비고 |
|---|---|---|---|
| 계정 별 저장 공간 | <code>/raid/계정명</code> | sv8ka[n1-n3], sv4ka[n1-n4],a100[n1-n4] | 계정 당 최대 300GB |

<aside class="warning">
사용자가 많아져 해당 경로가 가득차면(Disk Full) 다른 사용자를 위해서 디렉토리의 데이터는 <b style='color:crimson'>삭제</b>될 수 있습니다. 수시로 로컬 디스크의 데이터를 백업하고 정리하시는 것을 추천 드립니다.
<br>
인공지능융합센터에서는 수시로 용량을 검사하며, <u>한달 이상 방치된 파일</u>은 <strong style='color:crimson'>삭제</strong> 될 수 있음을 알려드립니다.
</aside>
